## מדריך התוכן

עד 14.11.2026 כתיבת התוכן נוהלה בחמישה מסמכים עם סדר קדימות ביניהם:
`writing-spec.md`, `voice-guide.md`, `content-guide.md` הראשון, ושני מסמכי גוגל
(`google-helpful-content.md`, `google-content-practical.md`). הם אוחדו
למסמך אחד, `content-guide.md`, הסתירות ביניהם הוכרעו בתוכו, והמסמכים הישנים נמחקו.
הם נמצאים בהיסטוריית git למי שצריך את הנוסח המקורי, למשל תרגום דף גוגל המלא.

הערות קוד ישנות בקבצי `content/authored/*.mjs` עדיין אומרות "Written to
docs/writing-spec.md". זה תיאור היסטורי של מה שהיה בתוקף כשהעמוד נכתב. מספרי
הכללים שהן מזכירות (סעיף 9, 10, 17 וכן הלאה) נשמרו בכותרות המדריך המאוחד.

ההחלטות הפתוחות על כללי התוכן רשומות בסוף `content-guide.md`.
