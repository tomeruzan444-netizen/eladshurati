# אלעד שורתי — אתר חדש

עיצוב מחדש של [elad-digital.co.il](https://elad-digital.co.il). כל התוכן, המטא-דאטה,
הקישורים הפנימיים והתמונות הועברו 1:1 מהאתר החי. **רק העיצוב השתנה.**

האתר הישן לא נגעו בו — כל התהליך קורא ממנו בלבד.

---

## הרצה מקומית

```bash
npm install
npm run serve       # http://localhost:4471 (also prints the LAN address for a phone)
```

לבנייה מחדש אחרי שינוי:

```bash
npm run build       # מייצר את site/ מחדש
npm run all         # extract → media → build → audit
```

לבנייה לסטייג'ינג (מוסיף noindex לכל העמודים, כדי שגוגל לא יאנדקס עותק כפול):

```bash
STAGING=1 npm run build
```

## הצינור

| שלב | סקריפט | מה הוא עושה |
|---|---|---|
| 1 | `1-crawl.mjs` | קורא את ה-sitemap של Rank Math ומוריד את ה-HTML של 63 הכתובות |
| 2 | `2-extract.mjs` | מפרק את ה-HTML לשכבת תוכן: SEO מלא + בלוקים מוקלדים, בלי ה-div-ים של Elementor |
| 3 | `3-media.mjs` | מוריד את כל התמונות — מהמארקאפ, מה-CSS, ומ-REST API של ספריית המדיה |
| 4 | `4-build.mjs` | מייצר את `site/` + `sitemap.xml` + `robots.txt` + `url-map.csv` |
| 5 | `5-audit.mjs` | ביקורת תוכן ו-SEO → `content/audit.json` |
| 6 | `6-linkcheck.mjs` | מוודא שכל קישור פנימי וכל תמונה בפלט באמת קיימים |
| 7 | `7-mobile.mjs` | בודק ב-320/360/390/430 שאין גלישה אופקית, שהעמוד נגלל, ושההדר נשאר נעוץ |

`npm run check` מריץ את 5–7 ברצף. שלב 7 דורש שרת תצוגה פעיל (`npm run serve`).

השרת מאזין על 4471 ולא על פורט נפוץ, ומסרב לחלוק אותו (`exclusive: true`). זה לא
קפריזה: פרויקט אחר על המחשב תפס 4321 במקביל, והבקשות התחלקו בין שני האתרים.
בעלייה הוא גם מוודא שהתשובה על `/` היא באמת האתר הזה.

סקריפטים נוספים: `optimize-images.py` (נגזרות רספונסיביות — להריץ אחרי כל שינוי תמונות),
`extract-brand.py` (חילוץ לוגו ופונטים מה-PDF), `cutout-portrait.py` (חיתוך רקע הפורטרט),
`gen-motifs.mjs` (מוטיבים גרפיים).

`RAW=1 npm run build` מדלג על מיניפיקציה — שימושי כשקוראים את הפלט.

## ביצועים

| | HTML | תמונות | סה"כ ביקור ראשון |
|---|---|---|---|
| עמוד הבית | 34KB | 200KB | **328KB** |
| עמוד נחיתה | 27KB | 76KB | **196KB** |
| פוסט | 26KB | 153KB | **273KB** |

משותף לכל העמודים (נשמר במטמון אחרי הביקור הראשון): CSS 37KB, JS 7KB, פונטים 49KB.

מה נעשה:

- **תמונות רספונסיביות** — כל תמונה נוצרת ב-AVIF ו-WebP בארבעה רוחבים, עם `srcset`
  ו-`sizes` מותאמים למקום שבו היא מוצגת. התמונות בעמוד הבית ירדו מ-2,864KB ל-200KB (‎93%‎).
- **פריסה סלקטיבית** — `site/` מכיל רק קבצים שהעמודים באמת מפנים אליהם. 84MB → 8.9MB.
  ספריית המדיה המלאה נשארת ב-`assets/`.
- **`preload` ל-LCP** — עמוד הבית טוען מראש את הפורטרט עם אותו `srcset` שה-`<picture>` יבחר.
- **פונטים** — subsets נפרדים לעברית וללטינית עם `unicode-range`, שני הקבצים הקריטיים ב-preload.
- **מיניפיקציה** — CSS ו-HTML. יש בדיקת בטיחות בבנייה שנכשלת אם המיניפייר שבר חישובי `calc`/`clamp`.

שמות ה-CSS וה-JS כוללים hash של התוכן (`site.ffedd15ad0.css`), ולכן `vercel.json`
נותן להם מטמון של שנה עם `immutable` — שינוי מייצר כתובת חדשה, אף פעם לא מטמון תקוע.

## פריסה ב-Vercel

`vercel.json` מגדיר הכל, אין מה להגדיר בממשק:

| | |
|---|---|
| `outputDirectory` | `site` — לא `public`, וזו הייתה שגיאת הפריסה הראשונה |
| `buildCommand` | `STAGING=1 node scripts/4-build.mjs` |
| `trailingSlash` | `true` — תואם למבנה `/עמוד/index.html` ולכתובות של האתר החי |
| `headers` | מטמון שנה ל-CSS/JS/פונטים/נגזרות, שבוע לשאר, ותוספי אבטחה |

### ⚠️ לפני שמפנים דומיין אמיתי

הבנייה רצה עם `STAGING=1`, כלומר **כל העמודים מקבלים `noindex, nofollow`
ו-`robots.txt` חוסם הכל**. זה מכוון: האתר החי עדיין באוויר עם אותו תוכן, ועותק
מאונדקס ב-`vercel.app` יתחרה בו על אותן מילות מפתח.

ביום העלייה לאוויר: להסיר את `STAGING=1` מ-`buildCommand` ב-`vercel.json`.
בלי זה — האתר החדש לא ייכנס לאינדקס בכלל.

## תנועה

- **כותרת עמוד הבית** — מפוצלת בזמן ריצה לשורות שהיא באמת נשברת אליהן, וכל שורה
  עולה מתוך מסכה משלה בהשהיה מדורגת. רק `transform` זז — הטקסט מצויר באטימות מלאה
  מהפריים הראשון, כך שה-LCP לא נדחה. בין שורה לשורה יש צומת רווח, כדי ש-`textContent`
  של ה-H1 יישאר מילה במילה כמו במקור.
- **חשיפה בגלילה** — IntersectionObserver יחיד, מפסיק לעקוב אחרי כל אלמנט ברגע שנחשף.
  כרטיסים בשורה נחשפים בהשהיה מדורגת.
- **פרלקסה בהירו** ו**פס התקדמות קריאה** — `animation-timeline: scroll()` של CSS, בלי JS בכלל.
- **תוכן העניינים** מסמן את הפרק הנוכחי תוך כדי גלילה.
- הכל מכבד `prefers-reduced-motion`, ומנפיש רק `opacity` ו-`transform`.
- יש רשת ביטחון: אם `site.js` לא נטען, אנימציית CSS חושפת הכל אחרי 4 שניות.

## המיתוג

**הפלטה הפעילה** היא "ליים וטורקיז על קרם", לפי הרפרנס שתומר אישר ב-25.8.2026.
היא גוברת על `ELAD-SHURATI-branding.pdf`, שקבע סגול/כתום/שזיף — המסמך ההוא
כבר לא בשימוש, כולל הלוגו הסגול-כתום שהוחלף בגרסת נייבי.

| | |
|---|---|
| קרם (רקע) | `#F8F5EE` |
| ליים | `#D9F650` |
| טורקיז | `#60DADB` |
| נייבי (טקסט) | `#080C29` |
| פונט מפרט | Discovery FS |
| פונט בפועל | **IBM Plex Sans Hebrew** — Light 300 / Regular 400 / Bold 700 |

הליים והטורקיז הם צבעי תצוגה — על קרם הם מגיעים ל-1.4:1 ו-1.8:1, ולכן משמשים
לרצועות, מילויים והדגשות בלבד. **טקסט תמיד נייבי.** יש גרסאות כהות
(`--turq-deep`, `--lime-deep`) לאותם מקרים שבהם אקסנט חייב להיות קריא.

כל הצבעים מוגדרים פעם אחת ב-`src/styles/tokens.css`. שמות המשתנים הישנים
(`--purple-500` וכו') נשארו כ-aliases שמצביעים על הפלטה החדשה — כך כל 63
העמודים התהפכו יחד, בלי להשאיר חצי אתר בסכמה הקודמת.

### למה IBM Plex Sans Hebrew

Discovery FS הוא פונט מסחרי ואין לו רישיון Webfont, ולכן חיפשנו חלופה חופשית.
הבחירה נעשתה במדידה ולא בעין: כל אות עברית עברה רינדור בשני הפונטים, נורמלה
לאותה תיבה, ונמדד חפיפת שטח (IoU) בין הצורות.

| פונט | Regular | Bold | ממוצע |
|---|---|---|---|
| **IBM Plex Sans Hebrew** | 70.9% | **81.0%** | **76.0%** |
| Heebo | 73.1% | 57.5% | 65.3% |
| Rubik | 59.4% | 47.1% | 53.3% |
| Assistant | 37.8% | 29.2% | 33.5% |
| Noto Sans Hebrew | 30.1% | 22.9% | 26.5% |

רישיון SIL Open Font License — חופשי לשימוש מסחרי בווב. מתארח מקומית
(`assets/fonts/`), 6 קבצים, 74KB בסך הכל — לעומת 207KB לכל משקל ב-Discovery.

הפונט רחב ב-3.8% וגובה האות גדול ב-16.6% מ-Discovery, כלומר הטקסט יוצא מעט
גדול יותר. השארנו כך — בעברית זה קריא יותר.

> אם יירכש רישיון Webfont ל-Discovery FS: מחליפים את בלוקי ה-`@font-face`
> בראש `src/styles/tokens.css` ואת `--font`. קבצי Discovery שחולצו מה-PDF
> שמורים ב-`_source/brand-fonts/` — **בכוונה מחוץ ל-`assets/`, כדי שלא ייפרסו.**
